# VetCairn Vaccinations

Preventive-care vaccination module for Odoo 19 Community. It provides species-
specific vaccine protocols, patient vaccination planning/history, calendar and
overdue queues, batch and expiry traceability, administration details, adverse
reaction notes, certificate references, and automatic booster due dates.

The module records clinical vaccination data only. Stock consumption, purchasing,
manufacturer integrations, automated messaging, and printable legal certificates
belong to later inventory, communication, and reporting phases.
