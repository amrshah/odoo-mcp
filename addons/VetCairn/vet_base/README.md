# VetCairn Base (`vet_base`)

Phase 1 foundation addon for Odoo 19 Community Edition.

## Included

- veterinary clinics with company isolation;
- veterinary clients extending `res.partner`;
- patient demographics, identifiers, lifecycle, species and breeds;
- multiple owners/guardians with one active primary owner;
- provider flags and clinic assignment on users;
- VetCairn role hierarchy and baseline access controls;
- menus, lists, forms, search views, chatter and activities;
- synthetic demo records and core model tests.

## Explicitly deferred

Appointments, consultations, medical notes, prescriptions, diagnostics, inventory,
billing, communications automation, and reports belong to later phases. No
production DaySmart data is included.
